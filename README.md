# DAMED-2020 — табло расписания

Одностраничное табло для телевизора: расписание врачей по дням недели, список кабинетов по этажам, местное время и текущая погода. Данные изменяются в админ-панели и хранятся в PostgreSQL, поэтому расписание с одного устройства видно на остальных.

## Запуск

1. Установите Docker Desktop.
2. Скопируйте `.env.example` в `.env` и задайте `POSTGRES_PASSWORD`, `ADMIN_PASSWORD` и `SESSION_SECRET`.
3. В корне проекта выполните `docker compose up --build -d`.
4. Откройте `http://localhost:8090` на телевизоре или компьютере. Нажмите кнопку настроек и войдите с паролем из `ADMIN_PASSWORD` в файле `.env`, чтобы добавить врачей и кабинеты.

Для доступа с других устройств в той же сети замените `localhost` на локальный IP-адрес компьютера, где запущен Docker.

## Публикация в интернете бесплатно

Проект подготовлен для Render и Supabase. React и Go запускаются одним Docker-контейнером на Render, база PostgreSQL хранится в Supabase.

1. Загрузите этот проект в свой GitHub-репозиторий.
2. Создайте бесплатный проект Supabase и скопируйте строку подключения PostgreSQL в режиме Session. Добавьте `sslmode=require` в параметры строки.
3. В Render выберите **New → Blueprint**, подключите GitHub-репозиторий и подтвердите создание сервиса. При настройке укажите строку базы и пароль администратора. Render сам создаст секрет для сессий.
4. После успешной сборки откройте адрес `*.onrender.com`. Это ссылка для телевизора и админ-панели; изменения синхронизируются через PostgreSQL.

Бесплатный веб-сервис Render засыпает после 15 минут без запросов, поэтому первый запуск после простоя может занять около минуты. Бесплатная база Supabase может приостановиться после 7 дней полного бездействия. Не используйте бесплатный хостинг для данных пациентов.

## Структура

- `frontend/` — React + TypeScript, адаптивное табло и админ-панель.
- `backend/` — Go API, парольный вход и сохранение данных.
- `docker-compose.yml` — React-сайт, Go API и PostgreSQL для локального запуска.
- `render.yaml` — настройки бесплатного веб-сервиса Render.

Начальный список врачей и кабинетов пустой. Название клиники, адрес, город и часовой пояс можно изменить в админ-панели. Погода загружается из Open-Meteo и требует доступа в интернет.
